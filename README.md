# NewEra

This project was rebuilt as a standard Vite + React + TypeScript app.

## Start

1. Install Node.js LTS on Windows.
2. Open this folder in VS Code.
3. Run `npm install`.
4. Run `npm run dev`.

## Notes

- Main app entry: `src/main.tsx`
- Routes: `src/App.tsx`
- Pages: `src/pages`
- Team images: `public/images/team`
